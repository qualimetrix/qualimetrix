# Э2 — счёт, живущий в коде, перестаёт дублироваться прозой без стража

Запись 1074 `../FOLLOWUPS.md`. Предмет не в том, что где-то написано не то число,
а в том, что число вообще написано: счёт живёт в коде, проза его копирует, и у
копии нет способа узнать, что оригинал сдвинулся. Правка чисел закрытием не
является — Х3-B1 выправил четырнадцать мест и промахнулся на пятнадцатом.

## Измерение, и почему первая редакция этого раздела была неверна

Первая редакция искала слово `fourteen` и объявила шесть расхождений. Ревью
опровергло два из шести и нашло седьмое, которого поиск не видел. Перемерено:

**Способ.** Прозаический текст всех файлов периметра (`scripts/finding-gate/*.php`,
`scripts/finding-gate-controls/*.php`, `finding-gate/README.md`) **разворачивается**
— снимаются префиксы `*`, `//`, `#` и переносы строк, — и в развёрнутом тексте
ищется числительное словом, за которым в пределах трёх слов стоит предметное
слово (`case`, `control`, `format`, `surface` и их множественные формы).
Артефакт: `enumeration-prose-counts.tsv`.

**Почему разворачивание, а не построчный поиск.** Построчно находится 97
утверждений, в развёрнутом тексте — 114. Семнадцать невидимы построчно, потому
что докблок переносит фразу; ровно в них и оказался настоящий дефект:
`Controls.php:504` говорит «the twelve tolerations name the twelve other cases»
при пятнадцати других кейсах, и фраза разорвана переносом между `other` и
`cases`. Страж, ищущий построчно, воспроизведёт этот промах машинно.

**Что из 114 действительно расходится с машиной.** Ревью второго раунда
опровергло первую версию этой таблицы: четыре места со словом «fourteen cases»
говорят **не об одном множестве**, и правка их по числу кейсов вписала бы в дерево
ложь.

| утверждение                                                 | места                                                    | машинный источник                                                        | сегодня | состояние  |
| ----------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------ | ------- | ---------- |
| «`coupling.class-rank` in all fourteen cases' `--rule-opt`» | `README.md:414`, `RenameMaps.php:50`, `SelfTest.php:614` | кейсы, чьи аргументы несут `coupling.class-rank` (`only-rules` не несёт) | **15**  | расходится |
| «`run-failed` on all fourteen cases»                        | `Controls.php:967`                                       | каталоги `finding-gate/cases/`                                           | **16**  | расходится |
| «the twelve tolerations name the twelve other cases»        | `Controls.php:504`                                       | каталоги кейсов минус объявленный                                        | **15**  | расходится |
| «twenty controls»                                           | `README.md:714`                                          | `Controls::all()`                                                        | 20      | верно      |
| «Eighteen negative controls … two green»                    | `Controls.php:14`                                        | `Controls::all()` с фильтром по исходу                                   | 18 + 2  | верно      |
| «twelve formats»                                            | `README.md:224`, `README.md:345`, `Control.php:220`      | `Surfaces::FORMATS`                                                      | 12      | верно      |

Расходятся пять мест, и за ними стоят **три разных машинных выражения**, а не
один счёт кейсов. Отсюда главное требование к инвентарю: строка называет
**выражение**, а не предмет. Инвентарь, ключующий строку словом «case», склеит
«всех кейсов» с «кейсов, несущих такой-то аргумент» и закрепит стражем ошибку.

Два места, названные первой редакцией (`Harness.php:41`, `Shell.php:329`),
считают не контроли, а гипотетическую ширину одновременности рядом с
`JOB_CEILING` — «Fourteen at once would not make the run fourteen times
shorter». Правка числа там испортила бы верный докблок.

- **Чего этот способ не видит:** числа цифрами; счёт, выраженный без
  числительного; прозу вне периметра гейта — сайт, `AGENTS.md`, планы.

## Решение

Страж по образцу
`tests/System/DocumentationConsistency/Integration/ChannelPublicationConsistencyTest`:
закрытый инвентарь утверждений, каждое привязано к машинному счёту, а
незарегистрированное утверждение той же формы — красный тест.

```php
// строка инвентаря: место, выражение и роль утверждения
// ['file' => …, 'line' => …,
//  'expression' => 'cases'                      — каталоги finding-gate/cases/
//                | 'cases_with_rule_opt:<key>'  — кейсы, чьи аргументы несут ключ
//                | 'controls' | 'controls_negative' | 'formats',
//  'role' => 'total'      — размер множества, которое называет выражение
//          | 'derived'    — арифметика над ним (N−1, «двенадцать других»)
//          | 'foreign'    — счёт другого машинного множества, с собственным выражением
//          | 'historical' — измерение прошлого прогона: сверяется не с машиной, а
//                           с датой и артефактом рядом, как решено в Э1 пакете D
//          | 'local'      — «one case», «two surfaces»: о размере не говорит ничего]

private function machineCount(string $expression): int;
private function statements(): array;   // развёрнутый текст периметра → найденные утверждения
#[Test] public function itAgreesWithEveryBoundStatement(): void;
#[Test] public function itRegistersEveryStatementOfTheSameShape(): void;
#[Test] public function itRefusesALocalRoleOnANumeralAboveTwo(): void;
```

Пять ролей, а не три: ревью нашло в 114 утверждениях два класса, которых
трёхролевая схема не покрывала. `foreign` — «the seven channels of that case's
computed family» (`README.md:846`), «the twelve findings the `smells` case
reports on that channel» (`Controls.php:918`): это ровно счёт, живущий в коде, он
дрейфует, но множество не кейсы, не контроли и не форматы. `historical` — «twelve
GitLab surfaces differed by 376 lines» (`README.md:296`), датированное в самом
тексте. Под трёхролевой схемой оба класса уехали бы в `local`, то есть были бы
освобождены именно те утверждения, ради которых страж пишется.

Третий тест — защита от неверной роли: `local` на числительном больше двух
запрещён, иначе «освобождено с причиной» станет способом обойти страж.

## Definition of Done

1. Три счёта (кейсы, контроли, форматы) привязаны к машинным источникам.
2. Пять сегодняшних расхождений исправлены по **своему** выражению каждое —
   три места про `--rule-opt` получают 15, `Controls.php:967` получает 16,
   `Controls.php:504` получает 15 как «других» — и покрыты стражем. Правка
   по общему счёту кейсов вписала бы ложь в три места из пяти.
3. Контроль на сам страж — по одной посаженной правке на каждый из трёх счётов:
   добавленный каталог кейса, добавленный элемент `Controls::all()`, добавленный
   элемент `Surfaces::FORMATS`. Каждая обязана покраснить страж, пока проза не
   поправлена. Проверяется на клоне, а не рассуждением.
4. Контроль на разворачивание: утверждение, разорванное переносом строки,
   находится стражем. Без этого случая страж проходит на сегодняшнем дереве,
   не умея того, ради чего написан.
5. Периметр и три класса невидимого названы в докблоке стража.
