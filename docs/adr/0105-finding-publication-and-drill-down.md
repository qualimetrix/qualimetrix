# 0105. Finding Publication and Drill-down

**Date:** 2026-10-08
**Status:** Accepted

## Context

Reports projected one finding with different keys and meanings. Some prose
replaced the diagnostic with advice, bounded lists cut before ranking, and the
HTML viewer recomputed values already published by the analyser. File findings
could disappear from a namespace view even when their file declared that
namespace. An old installed hook also described every non-zero analysis exit
as measured issues and recommended a baseline after an internal failure.

## Decision

### One record and truthful placement

FindingRecord supplies JSON violations, JSON topIssues and HTML records with
the same twenty fields, including rule, code, symbol, channel, exact subject,
occurrence, edge, namespace, complete namespaces, diagnostic, advice and baseline
judgement. Every Report supplies its captured FileNamespaceIndex; file membership
uses that same index for selection, grouping and record projection.
Message, recommendation and acceptedLevel status occupy separate presentation
slots. A baseline cap alone is not a measured breach: breached and not-compared
remain distinct. Formats with one slot append the truthful accepted-level text.
A fileless namespace finding names its namespace, using (global) for the empty
namespace; only a project finding uses [project]. Cycle recommendations contain
human guidance rather than an embedded JSON dump.

Bounded finding lists select severity first, then report impact ranking, before
the requested presentation grouping. A finding without rank falls back to its
place. This applies to JSON violation caps and text/summary detail caps. --top
continues to set the impact list's size; no second sorting option is introduced.
--format=text-verbose and its configuration value are removed; use text with
--detail=all to retain the complete detailed list.

### Published metric bags and browser consumers

HTML nodes carry their repository's bags, including the global namespace.
Named classes, interfaces, traits and enums use their own size.class-loc for
area; namespace/project nodes use their aggregate LOC. The viewer does not
invent health values, derive another subtree score or substitute MI for a
missing health.overall. An Other display bucket carries a private area weight,
not a manufactured public metric. Worst Sub-Namespaces displays the published
fractional score. Martin coordinates read coupling.* keys. Node placement and
debt keep each actual finding on one node.

A fixture generated by bin/qmx carries native metric bags and records into
browser tests. A freshness check compares the whole payload, normalizing only
installation version and generation time; vitest never starts PHP. Native
Rollup AST checks statically resolvable literal/dot/finite key expressions in
source and tests, including known bracket/optional/constant expressions.
Arbitrary runtime selectors, aliases, shadowed constants and general dataflow
are not proved by this census. Real DOM execution tests the dynamic selectors
the viewer uses on the native payload. Linkedom does not prove browser layout.
The independent harm is publisher/consumer drift missed by PHP unit tests, or
a stale committed fixture hiding it. Locally freshness took 1.509 seconds and
the viewer suite 0.947 seconds. A producer change correctly requires explicit
fixture regeneration; metadata normalization is deliberately narrow.

### Selection and suppression have different reach

Drill-down narrows publication, never measurement or the whole-run exit code.
FindingNamespace resolves a declared namespace from symbol then declaration
subject, excluding project subjects. The subject fallback preserves the
transport contract even though current detector producers already publish
their declaration symbols. FileNamespaceIndex carries declared file namespaces.
A namespace selector keeps a file aggregate if any declared namespace matches;
a file without declarations compares as the global namespace. A class selector
never selects a file aggregate. Namespace aggregation keeps its prior factual
contributions; presentation fallback does not add a new contribution.

suppress_namespaces does not use the file index: suppressing an entire
multi-namespace file by one namespace would hide the other namespace's code.
Use suppress_paths for a file aggregate. Overlapping namespace exclusions keep
first-match credit. Binding counts keep the same compared universe.

Out-of-scope identity is the occurrence-preserving multiset of channel, subject,
occurrence, optional edge and severity. JSON and metrics share the same count
and identity spelling. Metrics retains its own summary vocabulary
(violations, errors, warnings, info), while its outOfScope uses the shared
publication vocabulary (violationCount, errorCount, warningCount, infoCount).
This is an accepted cost: consumers combining selected and outside counts
read the two explicitly documented schemas; no second representation is
added to either object. SARIF publishes outside identities in a notification. GitHub retains
its ::notice. GitLab and Checkstyle refuse selectors because their consumer
would read a partial list as the whole result. suppressed is a whole-run
composition document and also refuses --namespace/--class. --show-suppressed
remains allowed with a selector and names its diagnostic list as whole-run,
with the selector unapplied. Health prints selected and outside finding counts
even when there is no health data.

### Terminal outcomes and generated hooks

InternalError is exit 5, distinct from warning findings at 1. The existing
typed refusal classifier remains authoritative: configuration and environment
carriers still return 3; incomplete analysis 4; baseline conflict and named
scope-guard failures keep their command outcome at 1. A bare unknown throwable
is internal. No blanket RuntimeException classification replaces the typed
boundary. Checkstyle refusal stdout stays empty; JSON-capable surfaces use
the shared error/exit_code/position/source envelope.

The generated pre-commit hook calls 1/2 measured issues, while 3/4/5 explains
refusal/incomplete/internal failure without baseline advice. Native shell
126/127 retains its binary execution diagnostic. A template hash identifies
the generated revision; hook:status names an owned old revision as outdated
and suggests qmx hook:install --force, retaining informational exit 0.
This does not promise that arbitrary edits retaining a revision marker are
equivalent to the template; the revision identifies the generating template.

## Consequences

Update HTML field readers and metrics outOfScope readers to the shared schema;
do not recompute the analyser's values in the browser. Review caps and namespace
views under the new selection semantics. Reinstall old generated hooks with
qmx hook:install --force and recognize internal exit 5 in external consumers.
Interface/enum GodClass behaviour with explicit min_criteria: 2 remains a
separate design-rule concern; the default does not claim missing cohesion.
