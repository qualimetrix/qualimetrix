# Измерения оркестратора X16 (снято на main == 4bb128fd)

Каждая строка — команда, которую можно повторить дословно.

## И1. `coverage.complete: true` в позициях 104/105 НЕ лжёт
`--namespace`/`--class` читаются в `FormatterContextFactory.php:79,81` и уезжают
в `FormatterContext`, то есть это фильтры ПРЕДЪЯВЛЕНИЯ, не анализа.
Анализ действительно полон; молча пустеет отчёт.
Следствие: формулировка брифа «продукт утверждает, что всё проверено, хотя
не проверено ничего» неточна. Лечение стоит на предъявлении.

## И2. Отказ ПОСЛЕ анализа механически доступен
`CheckCommand::execute()` (:159-178) оборачивает весь `doExecute` в
`try { } catch (ConfigurationRefusal) { refusalPresenter->refusal(...) }`.
Значит носитель, брошенный на предъявлении, даёт exit 3 штатно.
Развилка «отказ 3 против сигнала» решается по существу, а не по выполнимости.

## И3. Находке НЕ нужен декларационный субъект
`DeclaredLayerReachability.php:91-92,348-349`:
  subject: MetricSubject::aggregate(SymbolPath::forProject())
  symbolPath: SymbolPath::forProject()
`architecture.unreachable-layer` висит на проекте. Значит форма «находка»
доступна и дверям CLI, у которых своего субъекта нет.
Развилка НЕ расщепляется по источнику значения (CLI против YAML).

## И4. inert.tsv меряет ДРУГОЙ ноль
inert.tsv = ЭФФЕКТ-0 (суппрессор нашёл субъекты, но ничего не подавил).

Верхнеуровневых suppress_paths/suppress_namespaces в qmx.yaml НЕТ вовсе.

   на пробниках, а не на догфудинге.

## И5. Гейт нейтрален по привязке-0 — измерено, не предположено

  файл существует) и `rule-exclusion-ledger`

=> Лечение дверей 2,3,4,5,6 гейт не красит. Строка в `finding-gate/maps/`

## И6. Дефект оракула, названный ДО написания скрипта
Дифференциальная форма «промах != отсутствие => не молчит» ложно-зелёная:
у свидетеля Б промах `--format-opt=violation=2` дал diff 4 строки — ТОЛЬКО
timestamp. Направление ошибки худшее: молчание проходит как сигнал.
Оракул обязан (а) нормализовать через существующий `finding-gate/normalization.tsv`,
не изобретая свой, и (б) иметь ТРЕТИЙ исход «на фикстуре не наблюдаемо»
(случай строки 31 Б: `coupling.framework_namespaces` не наблюдаема ни на
промахе, ни на попадании). Вердикт о молчании засчитывается ТОЛЬКО при
наблюдаемом попадании.
