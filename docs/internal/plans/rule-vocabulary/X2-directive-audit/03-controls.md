# П3. Контроли на сам детектор

Детектор, всегда отвечающий «инертна», проходит наивную проверку: директив,
которые действительно ничего не делают, в дереве немного, и отчёт «инертных
ноль» выглядит одинаково у работающего детектора и у сломанного. Пакет
доказывает, что инструмент кусается.

Пакет стоит **до команды и до CI**. Прецедент — П0 захода Х1: инструмент
проверяется до продукта. Первая редакция плана ставила контроли последними, и
это нашли двое ревьюеров независимо: гейт, включённый в `composer check` до
доказательства детектора, — это enforcement на непроверенном измерителе.

## Контроли

Восемь. Первые две — парные пробы, остальные — мутации продукта на
hardlink-клоне (`cp -al`, и всегда `rm` файла перед записью в клоне).

| Проба                                                 | Ожидание                             |
| ----------------------------------------------------- | ------------------------------------ |
| заведомо действующая директива                        | `Effective`                          |
| заведомо инертная директива на **том же якоре**       | `Inert`                              |
| сравнение исходов всегда отвечает «совпало»           | краснеет: `Effective` → `Inert`      |
| снятие директивы ничего не снимает                    | краснеет тем же переходом            |
| сравнение исходов всегда отвечает «разошлось»         | краснеет: `Inert` → `Effective`      |
| снимается **первая запись группы** вместо всей группы | краснеет на классовой директиве      |
| из отпечатка убрана граница                           | краснеет: `Overrun` → `Effective`    |
| разбор коалиций выключен                              | краснеет: `Masked` → `Inert` на паре |

Первые две парные: сломанная адресация дала бы `Inert` обеим, и одиночная проба
этого не видит.

Три последние строки — прямой ответ на находки ревью: пять контролей первой
редакции проходили и на детекторе, который снимает одну привязку вместо группы,
и на детекторе с обеднённым отпечатком, и на детекторе без разбора коалиций.

Контроль на отпечаток снимает **и границу, и сообщение**: у правил, печатающих
границу внутри текста находки (`ComplexityRule.php:185`), одно поле дублирует
другое, и мутация, убирающая только поле, покраснеть не может. Это нашёл раунд 2,
и это ровно тот случай, когда контроль выглядит выполненной работой до первой
проверки его самого.

Фикстура для этого контроля берётся из правила, которое границу публикует:
`enumeration-boundary-publication.tsv` называет девять правил, которые её не
публикуют, и на любом из них контроль был бы вакуумен.

Мутации ставятся **поштучно**, и отдельно проверяется, что каждая красит именно
свой контроль. Мутация, красящая всё разом, не свидетельствует ни о чём;
мутация, ломающая загрузку класса, засчитана быть не может — она красит всё с
нулём ассертов.

## Фикстуры, которых требуют контроли

- Пара «действующая + инертная» на одном якоре и одном правиле.
- Классовая директива, чья группа содержит **больше одной** записи и чей исход
  зависит от записи, не являющейся первой, — иначе контроль на состав группы
  вакуумен.
- Пара класс+метод одного правила с совпадающим вердиктом — коалиция.
- Директива, чья величина уже прошла поднятую границу, — `Overrun`.

Каждая фикстура проверяется на то, что она вообще кусается: снятие директивы
двигает отчёт. Фикстура, не двигающая отчёт ни в одном состоянии, доказывает
только саму себя.

## Дом контролей

`scripts/finding-gate-controls.php`, если он принимает такие пробы, иначе
отдельный скрипт рядом с ним; в обоих случаях запуск через `composer` и явный
код возврата. Прогон с редиректом в файл, результат читается структурно.

## Definition of Done

- Восемь контролей исполняются и дают ожидаемое; шесть мутационных проверены
  поштучно, каждая красит свой контроль и не красит остальные.
- Каждая фикстура доказана кусающейся.
- `composer gate:controls` — exit 0; `composer check` — exit 0;
  `composer gate -- --reference=<коммит П2>` — GREEN.
- Манифест обновлён, если пакет завёл production-декларации.
- Коммит и полная цепочка до начала П4.
