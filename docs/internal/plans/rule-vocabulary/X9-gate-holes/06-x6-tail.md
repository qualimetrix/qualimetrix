# Этап F — хвост Х6: рост CPU под параллелизмом и wall-clock

Пакет F, только измерение; режется первым при нехватке ёмкости.

Открыто с Х6: суммарный CPU растёт с числом воркеров, гипотеза P/E-ядер
(Apple Silicon: воркеры расселяются на efficiency-ядра с меньшей удельной
производительностью) не проверена; wall-clock на свободной машине не снят.

Набор файлов: `followups/f.md`, таблица измерений на диске
(`X9-gate-holes/x6-cpu-measurement.tsv`).

Порядок:

1. Wall-clock и CPU (`/usr/bin/time -l`) для `bin/qmx check src/` при
   `--workers=0,2,4,8` на машине без конкурирующей нагрузки (зафиксировать
   фон: `top`-снимок до прогона в таблицу). По три повтора на точку,
   медиана.
2. Гипотеза P/E: `powermetrics` требует root и в пакет не входит; доступная
   замена — сопоставить рост CPU с превышением числа P-ядер
   (`sysctl hw.perflevel0.physicalcpu hw.perflevel1.physicalcpu`) и с
   формой кривой wall-clock. Если рост CPU начинается ровно за пределом
   P-ядер — гипотеза согласуется; это уровень уверенности, а не факт, и
   запись называет его гипотезой с наблюдением.
3. Итог в followup-запись: либо «объяснено наблюдением, закрыто», либо
   «наблюдение не согласуется, открыто с новым фактом».

уверенности; никакой правки кода.
