# Х3-E — предмет «авторская группа директив»

Закрывает запись `FOLLOWUPS.md` «Предмет „авторская группа директив" не назван,
и это он держит WMC». Гейт: нет — правка внутренняя.

Редакция вторая: ревью проверило контракты по коду и нашло четыре несовпадения
с фактической формой плюс инвертированный риск. Разделы «Контракты», «Кейсы» и
«DoD» переписаны целиком.

## Что измерено до планирования

Измерение 2026-09-02, ревью 2026-09-03 на дереве `84effeaf`. Способ:
перечисление токенизатором по `T_DOC_COMMENT`, второй проход по чтению ключей
массива, сверка списков, прогон продукта с `--format=metrics`, контрольное
удаление методов на копии.

**Форм три, а не одна**: сама группа `array{file, line, rule, bindings}`; группа
вместе с сайтом; обёртка `{group, effect, reason, maskedBy}`. Плюс четвёртая
форма у производителя — keyed-map `array<string, array{…}>`, в которую пишут
инкрементально (`$groups[$key]['bindings'][] = …`). Неизменяемый объект её не
принимает: производителя придётся перестроить (накопить, потом сконструировать).

**Счёт подтверждён независимо**: пятнадцать строк `@param`/`@return` с формой,
распределённых по двенадцати методам, в двух файлах.

**Носителей без аннотации не пять, а не меньше шести** — локальные накопители в
аудите и в коалиции плюс распаковка `$group = $entry['group']`. Число без списка
здесь бесполезно: смысл раздела в перечислении, поэтому таблица мест — часть
DoD, а не приложение.

**Типы полей не те, что казались.** `file` — `string` и используется как **ключ
массива** в аудите; `RelativePath` из него делает уже `site()`. `subjects()`
возвращает `list<string>` (канонические строки), а не `list<MetricSubject>`, и
единственный содержательный потребитель — `array_intersect`, который сравнивает
приведением к строке.

**Сайт сравнивается по идентичности объекта.** `hiddenBy()` проверяет
`$masker['site'] !== $candidate['site']`, а сайт кладётся в группу один раз.
Если пара «распадается на вызов `site()`», сравнение станет всегда истинным —
кандидат перестанет исключаться из чужих, и алгоритм молча изменит ответ. Это
ровно то место, которое первая редакция объявила производным и закрытым.

**Производитель ровно один**; потребителей, читающих ключи, двадцать четыре
строки в двух файлах; форму целиком не читает никто.

**Метрики и их механизм.** Аудит: WMC 41 при пороге 50, `health.cohesion` 50,
14 методов. Коалиция: WMC 15, когезия 50, 6 методов. Оба ровно на пороге, но
**не потому, что «поля разъедутся»**: `cohesion.tcc` у обоих отсутствует вовсе,
и при `size.method-count >= 6` подставляется ноль; вторые 50 приходят от
`cohesion.lcom = 1`. Рычагов два: `lcom` и обрыв на шести методах.

**Риск инвертирован — измерено контрольным удалением.** Убрав `site()` и
`subjects()` из копии коалиции (6 → 4 метода): `health.cohesion` 50 → 85.36,
`health.overall` 87.5 → 96.34, WMC 15 → 13. Для коалиции выделение — улучшение,
а не риск. Для аудита (14 методов) обрыв недостижим, `lcom` от выделения типа не
растёт, и когезия останется 50.

**Место и манифест.** `src/Analysis/Policy/Inline/Directive/`, `visibility: internal`,
владелец `Analysis.Policy.Inline`; `Contract/` не нужен. Consumer-строки живут на
импортируемой декларации: потребуются у `Core\Path\RelativePath` (если
`RelativePath` вообще попадёт в тип) и у `Analysis\Finding\Contract\Threshold\ThresholdOverride`;
`DirectiveSite` — одного владельца и строки не требует, но лежит в
`Contract/Directive`, а не в `Directive/`. У коалиции строку `ThresholdOverride`
снимать нельзя: импорт там остаётся.

## Архитектурное решение

**Назвать группу типом и отдать ей то, что о ней знают другие.**
`AuthoredDirectiveGroup` — неизменяемый объект с полями группы, владеющий
`site()` и `subjects()`, которые сегодня живут публичными статиками на классе
коалиции. Аудит и коалиция зависят на него; он не зависит ни на кого из них.

**Типы полей сохраняются как есть.** `file` остаётся `string`, потому что он
служит ключом массива у потребителя; `subjects()` остаётся `list<string>`,
потому что пересечение сравнивает строки. Менять их — отдельный предмет
(«идентичность группы») со своей ценой; смена типа заодно с выделением класса
дала бы молчаливую поломку пересечения и ключей.

**Сайт мемоизируется в объекте.** Он вычисляется один раз при создании и
возвращается тем же экземпляром — тогда сравнение по идентичности продолжает
работать, а форма «группа плюс сайт» исчезает честно, а не переносом дефекта.
Альтернатива (сравнение сайтов по значению) шире по последствиям и в этот пакет
не входит.

**Обёртка исхода получает свой тип.** `{group, effect, reason, maskedBy}` — это
суждение о группе, а не сама группа; без своего типа объектом закрывается треть
мест.

**Производитель перестраивается.** Keyed-map с инкрементальной записью
накапливается как раньше, но результат конструируется один раз в конце.

## Контракты

```php
// Analysis\Policy\Inline\Directive
final readonly class AuthoredDirectiveGroup
{
    /** @param list<ThresholdOverride> $bindings */
    public function __construct(
        public string $file,          // остаётся строкой: служит ключом массива у аудита
        public int $line,
        public string $rule,
        public array $bindings,
        private DirectiveSite $site,  // вычислен один раз; сравнение по идентичности сохраняется
    ) {}

    public static function of(string $file, int $line, string $rule, array $bindings): self;
    public function site(): DirectiveSite;
    /** @return list<string> канонические субъекты, как сегодня */
    public function subjects(): array;
}

final readonly class MaskingOutcome
{
    public function __construct(
        public AuthoredDirectiveGroup $group,
        public DirectiveEffect $effect,
        public ?DirectiveUnmeasurableReason $reason,
        public ?DirectiveSite $maskedBy,
    ) {}
}
```

Двенадцать сигнатур меняют `array` на тип; шесть и более носителей без аннотации
получают тип впервые — их находят вторым проходом, а не по докблокам.

## Кейсы и граничные условия

- **Маскирование проверяется юнит-кейсами, а не выводом на `src/`.** Измерено: в
  `src/` нет ни одного файла с двумя `@qmx-threshold` одного правила, а субъекты
  директив из разных файлов не пересекаются, поэтому `hiddenBy()` на нашем дереве
  не исполняется вовсе. Побайтное сравнение вывода зелено при любой поломке
  маскирования. Нужны кейсы с двумя и более маскерами.
- Порядок групп задаётся производителем и наблюдаем в отчёте; тип не имеет права
  его менять.
- Пустые `bindings` допустимы.
- `subjects()` из статики становится методом экземпляра; вызывающий без объекта
  означает, что массив рождается вне производителя — такое место называется, а
  не обходится статикой на новом типе.

## Definition of Done

1. Перечисление мест снято заново двумя способами и **приведено таблицей**
   (файл, метод, форма). Число мест, оставшихся с массивом, названо; ноль —
   цель.
2. Юнит-кейсы коалиции с двумя и более маскерами зелёные и проверены снятием:
   верни сравнение сайтов на `!==` без мемоизации — кейс обязан покраснеть.
3. `bin/qmx check src/ --format=metrics` до и после: WMC и `health.cohesion`
   **четырёх** классов — аудита, коалиции и обоих новых. Ожидание из измерения:
   коалиция улучшается (6 → 4 метода), аудит не меняется. Расхождение с этим
   ожиданием — повод остановиться и объяснить, а не ратчетить.
4. Вывод `bin/qmx directives src/` побайтно совпадает до и после. Это
   свидетельство о неизменности отчёта, а не о маскировании (см. пункт 2).
5. Манифест дополнен руками, `composer architecture:check` — 0, генерируемое
   перегенерировано.
6. `QMX_MKDOCS=<основной checkout>/website/.venv/bin/mkdocs composer check` — 0.
7. `composer directives:controls` — 0. Мутации пробников привязаны к тексту
   исходника аудита и коалиции и почти наверняка потребуют правки — это часть
   пакета, а не сюрприз; после правки каждый затронутый пробник проверяется
   снятием.

## Раскладка: `Directive/Audit/` вместо роста корня

Пакет добавил в `Policy\Inline\Directive` два класса, и `size.class-count`
встал на пороге: 15 при 15. Порог не трогали и в ратчет ничего не клали —
метрика моделирует дизайн верно: предмет действительно вырос на два класса.

Первым предложением был разрез по сквозному аудиту порогов — пять классов
(`ThresholdDirectiveAudit`, `DirectiveMaskingCoalition`, `ExecutionFingerprint`,
`AuthoredDirectiveGroup`, `MaskingOutcome`). **Он отвергнут по измерению**, и
это записано здесь, а не подразумевается.

Измерено по `git log -M`, 29 коммитов, трогающих классы корня:

| разрез                     | внутри / снаружи | коммитов трогает группу | из них выходят наружу | партнёры по выходу                              |
| -------------------------- | ---------------- | ----------------------- | --------------------- | ----------------------------------------------- |
| A: только сквозной аудит   | 5 / 10           | 12                      | **5 (42 %)**          | `DirectiveUsage` ×5, `InlineDirectivePolicy` ×3 |
| **B: обе половины отчёта** | **7 / 8**        | 16                      | **4 (25 %)**          | `InlineDirectivePolicy` ×4                      |
| C: B + адресуемость        | 8 / 7            | —                       | 11                    | —                                               |

**Тест «имя».** У A имя предметное («что сделала авторская `@qmx-threshold`, по
разности исхода»), но обнажает асимметрию: `DirectiveUsage` — «что сделала
каждая авторская суппрессия» — зеркальная половина того же отчёта
`qmx directives`, и она осталась бы в родителе. У B имя симметрично и
асимметрию снимает: **«что сделала каждая авторская директива, обе половины»**.
В корне остаётся сама директива — хранилище прогона, адресуемость, уровни,
валидация, подсказки имён.

**Тест «со-изменение».** У A ответ отрицательный: `DirectiveUsage` —
сильнейший партнёр аудита (5 из его 12 коммитов) и присутствует **в каждом**
выходящем коммите; разрез клал бы ребро со-изменения весом 5 поперёк новой
границы. У B остаток 25 % и идёт целиком через `InlineDirectivePolicy` — это
хранилище директив прогона, хаб, который читают обе половины, а не
предмет-ровня.

**Тест «дублирование».** Проходят оба: ни A, ни B не пришлось бы копировать в
каждый предмет при полном разложении.

**Цена принята сознательно.** B задевает `DirectiveUsage` и
`StaleDirectiveFinding`, которых исходный объём Х3-E не касался. Пакет упёрся в
порог собственным дизайном, и верная раскладка дешевле красного порога,
оставленного «на потом».

Перенос идёт **внутри одного владельца** `Analysis.Policy.Inline`, поэтому граф
слоёв qmx не меняется — измерено: 37 owner-слоёв, 0 seam, 13 coarse-рёбер до и
после. Тесты остаются на прежних путях: владение тестами в манифесте ключуется
владельцем, а не подпредметом, и `Integration/` в этом дереве и так не
зеркалит подпредметы.

Числа: `size.class-count` 15 → **8** в корне и **7** в `Audit/`.

## Что пакет не закрывает

Типы полей группы (`file` как строка, субъекты как канонические строки) остаются
прежними: их смена тянет ключи массивов и пересечение субъектов. Запись об этом
заводится тем же коммитом — вместе с измеренной причиной, чтобы следующий заход
не начал с «просто типизировать».
