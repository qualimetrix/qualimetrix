# Запись для FOLLOWUPS.md — этап A захода Х9

## Х9 (2026-09-05) — гейт объявляет то, на чём Э2 прошёл молча

### Обе дыры компаратора закрыты, и Э2 доказан задним числом

Записи Х8 «Гейт не выражает переименование корневого ключа конфигурации» и
«Переименование значения поля отчёта не покрыто ни одной картой гейта»
закрыты пакетом А1: `assertWholeInputToken()` принимает четвёртую форму —
ключ в написании документа (`exclude_paths:` с двоеточием), а пятая карта
`finding-gate/maps/report-values.tsv` объявляет значение перечислимого поля
отчёта (forward-only, только `format:suppressed`, подстановка только в
кавычках — голой подстановки у роли не существует по построению).
Ограничение четвёртой формы названо в README вслух: она адресует ключ так,
как его пишет документ, а не «у какого правила», — переименование опции у
одного правила при том же имени у другого по-прежнему невыразимо.

После правки компаратора `composer gate:controls -- --reference=main` — PASS
23 из 23, включая три новых контроля (два зелёных поглощения объявлением и
красный на значение механизма без строки, с производным списком ожиданий по
всем кейсам). Попутно контроли отремонтированы там, где дерево дрейфанул от
них до Х9: пять delta-контролей создают `declared-delta.tsv` в клоне, а
мутация `rename-no-map` догнала переезд `magnitude()` → `judging()`.

Запись «Чем доказана эквивалентность находок Э2, раз гейтом её доказать
нельзя» закрыта прогоном, которого не хватало:
`composer gate -- --reference=730941c1` — **GREEN**, сравнение ревизий
через границу Э2 состоялось (лог прогона — коммит `c17314c0`, сводка ниже).
Состав доказательства: две строки четвёртой формы, четыре строки пятой
карты (все сработали), девять объявленных дельт и четыре лицензии
`declared-field-moves.tsv`.

- **Чего доказательство потребовало сверх ожидаемого, и это само по себе
  находка:** Э2 подвинул не две поверхности, а девять. Кроме judged-строк
  `qmx rules` и stderr-сводки per-rule подавлений словарь переехал в прозу
  подсказки `architecture.empty-template` (`` `suppress_paths` `` в
  бэктиках) — семь поверхностей кейса `layers`, из них четыре структурных
  формата потребовали типизированных лицензий на движение поля `message`.
  Ни одна карта такое не выражает и не должна: проза — структурная дельта,
  и механизм Ш6 (`declared-field-moves.tsv`) сработал по назначению в свой
  первый настоящий раз.
- **Жизненный цикл соблюдён:** объявления жили один коммит (`c17314c0`) и
  сняты следующим — дерево держит пустые карты, ни одной дельты и ни одной
  лицензии; `composer gate -- --reference=main` после снятия — GREEN.
- **Что остаётся правдой:** переименование, чей след — голое слово в прозе
  сообщения, каждый раз будет требовать объявленной дельты (и лицензий на
  структурных форматах). Это цена честности компаратора, а не дыра.
