# Запись для FOLLOWUPS.md — пакет C3 захода Х9

## Х9 (2026-09-05) — две половины вселенной каналов складываются одной командой

FOLLOWUPS «52 канала — статическая половина вселенной, и вторая не
перечислена» закрыта: `composer enumeration:channel-universe` печатает обе
половины и их сумму, не сливая файлы — у половин разное время разрешения
(статическая — компиляция контейнера, рантайм-половина —
metric-lookup из конфигурации), и слияние соврало бы о том, когда канал
известен.

Вывод команды (дерево Х9, `enumeration:runtime-channels:check` зелёный на
том же дереве):

```
Channel universe, two halves, two resolution times — never merged into one file or one count:

  STATIC   52 channels   resolved once, at container-compile time
           source: docs/internal/plans/rule-vocabulary/X8-one-string-two-jobs/enumeration-channels.tsv

  RUNTIME  7 channels   (6 builtin + 1 corpus-observed), resolved later, at metric-lookup time from configuration
           source: docs/internal/plans/rule-vocabulary/enumeration-runtime-channels.tsv (re-derived here; run --runtime-channels --check to prove the file agrees)

  TOTAL    59 channels   = STATIC + RUNTIME

The corpus-observed count is a lower bound: a computed metric declared in a
qmx.yaml outside the gate corpus is not enumerable, only observable, and only
over the corpus this run read.
```

- **Реализация:** новый режим `--channel-universe` в
  `scripts/generate-rename-enumeration.php`, читает статический счёт из
  собственного артефакта половины (`staticChannelCount()` — строки минус
  комментарии минус шапка колонок), рантайм-половину пересчитывает тем же
  `runtimeChannelRows()`, которым уже пользуется
  `--runtime-channels`. Ничего не пишет на диск — только печать; отдельного
  `:check`-режима не заводилось, т.к. команда не производит артефакт, чью
  свежесть было бы что проверять.
- **Алиас:** `composer enumeration:channel-universe` в `composer.json` —
  только новый алиас, существующие записи не тронуты.
- **Шапка статической таблицы:** `X8-one-string-two-jobs/enumeration-channels.tsv`
  получила комментарий-преамбулу «this table is about the static half»,
  называющую время разрешения, ссылку на `enumeration-runtime-channels.tsv`
  для второй половины и саму команду. Файл не генерируется скриптом (сноска
  внизу — ручная сводка Х8), поэтому правка руками, а не перегенерацией; ни
  один `check:artifacts`-шаг эту таблицу не проверяет на свежесть
  (`grep` по дереву на `X8-one-string-two-jobs/enumeration-channels.tsv` вне
  докладов и планов ничего не находит), так что правка ничего не красит.
- **Докблок `ChannelDeclarationCompilerPass.php:90-97`:** переформулирован —
  computed-metric семейство отсутствует в списке `JudgedMetricDeclarationGuard`
  по времени разрешения (после того как этот компилятор-пасс уже
  отработал), а не по недосмотру; числа в прозе не повторяются, адрес
  канона — новая команда.
- **Числа не повторены прозой** ни в новой команде (тексте вокруг неё в этой
  записи цитируется вывод, а не переносится как отдельное утверждение), ни
  в докблоке компилятор-пасса — оба указывают на артефакты/команду.
