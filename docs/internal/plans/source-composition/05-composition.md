# Этап 05. Лечение композиции

**Этот этап пишется после гейта этапа 03.** Здесь зафиксировано направление,
измеренная цена и три вопроса ADR 0055. Списки файлов пакетов появятся, когда
сетка назовёт, что именно сломано, — иначе пакет лечит гипотезу.

Основание для такой формы: в X17 шесть посылок брифа проверялись измерением,
и четыре пакета из шести измерение опровергло — каждый раз по-новому.

## Направление — рабочая гипотеза, а не принятое решение

Различение существенно, и ревью справедливо указало, что первая редакция его
смазала: обещать «этап пишется против сетки» и тут же зафиксировать
архитектуру — значит отложить только списки файлов. Поэтому явно: всё ниже —
**гипотеза**, которую этап 03 вправе отвергнуть. Отвергнуть её может, в
частности, сетка, показавшая, что потери слота не происходит там, где
знаменатель считал её возможной, или что вытеснение — не единственный её
механизм.

## Гипотеза

Один разрешённый документ опций правила, собираемый один раз, в порядке
«сворачивание написаний → раскрытие точечной нотации → раскрытие сокращения
`threshold` → слияние», читаемый всеми потребителями.

Что из этого следует для трёх вопросов ADR 0055:

**Раскрытие сокращения до слияния.** Тогда вытеснение режима не нужно вовсе:
слои сливаются, когда обе стороны уже говорят на одном языке полос, и тройка
`G → T → G` перестаёт иметь механизм потери. Это и есть ответ на вопрос,
почему три решения нельзя принимать порознь.

**Реестр групп и его эвристика.** Если сокращение раскрыто до слияния, знание
«эти ключи — один слот» нужно **раньше** и в другом месте: рядом с объявлением
формы, у класса опций. Реестр из 33 записей над 22 правилами и суффиксная
эвристика для остальных 26 тогда не нужны. Популяционный страж стенда X17
намеренно на них не опирается — именно потому, что этот заход вправе их
удалить.

**Второй читатель.** `RuleOptionsRegistry::all()` — путь без вытеснения, без
раскрытия точек и без сворачивания написаний; у него 4 потребителя. Если
документ один, второго пути нет.

## Цена, измеренная разведкой

Поверхность перечислена в [`measurement/axis-c-surface.tsv`](measurement/axis-c-surface.tsv).

| место                             | размер                                                | чем опасно                                                                                                                                                                           |
| --------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ThresholdParser::parse()`        | **31 вызов в 30 файлах**, каждый внутри `fromArray()` | самое дорогое и самое незаметное: разворот сокращения живёт не в фабрике, а в каждом классе опций                                                                                    |
| объявление групп у классов опций  | 22 класса с записями + **26 правил без единой**       | у 26 сегодня решает суффиксная эвристика; направление обязано либо объявить группы для всех, либо оставить эвристику постоянным запасным путём — что противоречит самому направлению |
| `RuleOptionThresholdModeResolver` | слияние знает `$ruleName`, но не класс опций          | чтобы группы читались с класса, его придётся протащить через всю рекурсию слияния                                                                                                    |
| `RuleOptionKeySet`                | понятия «эти ключи — один слот» нет вовсе             | новая сущность, а не расширение существующей                                                                                                                                         |
| `RuleConfigurationInterface`      | инъекций 11, реальных вызовов `all()` — 4             | контрактный слом; есть тестовый дубль, реализующий интерфейс напрямую                                                                                                                |

Поверхность снята **только по `src/`**. Вызовы из `tests/` в неё не входят, и
это названо, а не подразумевается: при декомпозиции пакетов тестовая
поверхность считается отдельно, иначе пакет, зелёный по своему набору файлов,
уронит чужие тесты.

**Опаснейшее место, которое сетка обязана осветить до лечения.** Три из
четырёх потребителей `all()` читают framework-ключи (`suppress_paths` и
соседние), а `RuleOptionsFactory::create()` вырезает их из документа **до**
`fromArray()`. Устроить единый документ по образцу `create()` — значит молча
оставить трёх потребителей читать пустоту. Четвёртый потребитель эквивалентен
уже сегодня. Это не деталь реализации: это вопрос о том, один ли документ
вообще, или их два с разными границами.

## Что этап обязан сделать до первого пакета

1. Взять число дефектов оси C из этапа 03 и назвать, какие из перечисленных
   выше мест **сетка подтвердила как сломанные**, а какие — нет.
2. Перечислить все места, где сегодня принимается решение «этот ключ —
   режимный», по каналам: прямой вызов, строковый идентификатор, DI, рефлексия,
   атрибут, тест. Назвать непокрытый канал. Разведка нашла один непокрытый:
   для 26 правил без записи решение принимает эвристика, и её не фиксирует ни
   атрибут, ни тест.
3. Назвать тесты, закрепляющие сегодняшнее поведение и переворачивающиеся.
4. Пересчитать поверхность по каналам «текстовое совпадение», «выражение
   вызова» и «файл, реально содержащий вызов» — пакеты строятся по последнему.
   Первый счёт этого захода дал 41/32 вместо 31/30 именно потому, что `grep`
   считал докблоки.
5. Разложить работу на пакеты с **непересекающимися наборами файлов**. Смена
   сигнатуры, зовомой из 30 файлов, блокирует верификацию всех соседей в том
   же дереве: такой пакет идёт в одиночку либо в отдельном worktree.

## Definition of Done

1. Каждый дефект оси C, названный этапом 03, либо вылечен, либо переведён в
   `DEFERRED` строкой с ценой.
2. ADR 0056 отвечает на все три вопроса ADR 0055 **вместе** и называет
   отвергнутые альтернативы.
3. Если реестр групп удалён — популяционный страж стенда перестаёт быть слеп к
   его записям, и это проверяется подсадкой.
4. Если `all()` удалён — каждый из четырёх потребителей получил названный
   источник, и для трёх framework-читателей доказано **прогоном**, что они
   читают то же, что читали.
5. `composer check` целиком зелен; `composer gate -- --reference=02a6ca66` в
   своей роли зелен.
