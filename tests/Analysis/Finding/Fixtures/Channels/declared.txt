# Tracked fixture: the STATIC channel declarations verified at their
# emission point against the channel declaration registry.
#
# Format (one channel per line, sorted, blank lines and '#' comments ignored):
#   <ruleName>#<violationCode> <shape>[:<direction>] <levels> [<acceptability>]
#     shape         := magnitude | occurrence
#     direction     := higher | lower   (magnitude channels only)
#     levels        := comma-separated SymbolLevel values, in enum case order,
#                      never empty -- the levels the channel reports at
#     acceptability := config-error     (omitted = acceptable as debt)
#
# `config-error` marks a channel whose findings report a mistake in the
# *configuration* rather than debt in the code: it can never be accepted by
# a baseline on any path, and it fails the run without consulting `fail_on`.
# Eight channels carry it today: the five layer-policy diagnostics, and the
# three inline-directive diagnostics that report a directive which can never
# do what it says. The two channels that sit beside them and deliberately do
# not are architecture.layer-violation (a forbidden dependency edge is real
# code debt) and annotation.unused-directive (a leftover suppression is
# ordinary cleanup, not a mistake).
#
# The drift guard
# (tests/Analysis/Finding/Integration/ChannelDeclarationFixtureDriftTest.php)
# compares this file against
# ChannelDeclarationRegistryInterface::staticDeclarations() in both
# directions: a channel declared in code but missing here fails, and a line
# here no longer declared in code fails. It is scoped to the STATIC set
# only — the run-time computed.*/health.* family is guarded separately (see
# excluded.txt's note and
# tests/Infrastructure/Unit/ChannelUniverseTest.php's
# run-time resolution cases) because its vocabulary is open-ended and no
# fixture line could enumerate it.
#
# P1a of the ADR 0017's P1 declared three static channels end
# to end to prove the mechanism (code-smell.goto, complexity.cyclomatic.callable,
# maintainability.index). P1b fills in every other static emission point in
# violation-magnitude-inventory.md, per the shape mapping and the four named
# families of ADR 0017. One emission point remains deliberately outside this
# file: annotation.unsupported-threshold / annotation.invalid-threshold(.*),
# excluded outright by ADR 0017 — see excluded.txt.
#
# code-smell.unused-private has no gating threshold comparison (the rule
# fires on any nonzero count; severity is a fixed constant) but is declared
# `magnitude`/`higher` anyway, as a decision rather than a derivation — the
# same class of decision as architecture.circular-dependency: a threshold is
# not what establishes direction, the meaning of the measured value is, and
# more unused private members is unambiguously worse debt. See the rationale
# on UnusedPrivateRule::channelDeclarations().
#
# Do not add a line here without reading that channel's own emission point
# first — never by analogy with a neighbouring line.
