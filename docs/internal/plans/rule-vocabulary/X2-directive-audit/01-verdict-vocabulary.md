# П1. Вердикт становится значением, и у него один универсум

Сегодня ответ «подавление ничего не погасило» существует только готовой
`Finding`, которую строит `DirectiveUsage::stale()`. Команде нужен тот же ответ
строкой отчёта, и второй вычислитель был бы вторым источником правды.

Сверх того пакет чинит дефект проводки: аудит подавлений судит по
опубликованному, а обязан — по произведённому.

Пороговой половины здесь нет, она в П2.

## Дефект универсума и его цена

`AnalysisPipeline::reportedFindings()` берёт `$ruleExecution->published` и
передаёт в `auditInlineDirectives()`. `published` — это `produced` после
`FindingExclusionLedger::keeps()` (то есть после `exclude_namespaces`,
`exclude_namespace_channels`, `exclude_paths` продюсера) и после канальной
селекции. Значит подавление, гасящее находку, которую ledger всё равно выбросил
бы, сегодня объявляется неиспользованным: суждение об аннотации выводится из
настройки отчёта.

Исправление: аудит подавлений получает `produced`.

**Дельта измерена до правки, и она пуста — по построению, а не по совпадению.**
`SuppressionFilter::suppressesAny()` — экзистенциальная проверка по списку
находок, поэтому переход к надмножеству (`produced ⊇ published`) может только
превратить «ничего не погасило» в «погасило», и набор инертных монотонно
убывает. На нашем `src` этот набор сегодня **пуст** (прогон `bin/qmx check src/
--format=json --workers=0`: 229 находок, из них канала
`annotation.unused-directive` — ноль), а в `qmx-baseline.json` канал не
встречается ни разу. Убывать нечему.

Отсюда два следствия, и оба обязаны быть названы, а не обойдены:

- правка **превентивная**: сегодня она ничего не чинит на нашем дереве, а
  закрывает механизм, который выстрелит на первом же подавлении, попавшем под
  исключение продюсера;
- **наше дерево свидетелем быть не может**, поэтому единственный свидетель —
  фикстура из тестового плана, и мутация «судить по `published`» обязана
  краснеть именно на ней. Зелёный `src` тут не доказывает ничего.

## Контракты

Новое, в `Analysis\Policy\Inline\Contract\Directive`:

```
enum DirectiveEffect { Effective; Overrun; Inert; Unmeasured; }

enum DirectiveUnmeasurableReason {
    ProducerDisabled;      // селектор или rules: { X: false } — оба способа
    AlreadyRefused;        // отказанная пара channel:level, неразворачиваемый
                           // селектор, канал без продюсера — на всё это уже
                           // отвечает annotation.unresolved-directive
    AddressesEveryChannel; // директива без фильтра правил
    Masked;                // перекрыта другой директивой того же правила (П2)
}

final readonly class DirectiveVerdict {
    public RelativePath $file;
    public int $line;
    public string $form;      // как написано: тип директивы, а не семейство
    public string $target;    // селектор, как написан автором
    public DirectiveEffect $effect;
    public ?DirectiveUnmeasurableReason $reason;   // непустая ровно при Unmeasured
    // maskedBy и boundaryObservable добавляет П2 — вместе с тем, кто их заполняет
}
```

`form` хранит **тип директивы**, а не семейство: ключ авторского сайта в
`DirectiveUsage::groupByAuthoredSite()` и в
`InlineDirectivePolicy::onePerAuthoredSite()` включает `SuppressionType`, у
которого три значения, и склейка их в одно «игнор» сделала бы вердикт грубее
обоих существующих ключей — отчёт не смог бы сказать, какой из тегов снимать.

Изменения в `DirectiveUsage`:

```
/** @return list<DirectiveVerdict> */
public function verdicts(array $suppressionsByFile, array $findings): array

/** @return list<Finding> — проекция verdicts(), оставляющая Inert */
public function stale(array $suppressionsByFile, array $findings, Severity $severity): array
```

**Видимость и место определяются потребителем, а не намерением.** Проверяющий
манифеста отвергает запись потребителя, которого ещё нет, а ADR 0022 разрешает
`Contract/` только для типов, которые читает названный чужой владелец. Пока
вердикты читает один Inline, они живут рядом с `DirectiveUsage`, `internal`, и
переезжают в `Contract/` в том пакете, где появляется чужой читатель — в П2
(пайплайн) и в П4 (команда). Операция на `InlineDirectivePolicyInterface`,
через которую вердикты пересекают границу владельца, заводится **в П2**, вместе
со своим единственным читателем: заведённая здесь, она была бы мёртвым кодом до
следующего пакета.

`Overrun` и `Masked` в П1 не порождаются — их порождает пороговая половина.
Словарь `DirectiveEffect` объявляется целиком сразу, потому что замораживается
он не здесь, а в П4, когда попадёт в JSON; поля вердикта, которые заполняет
только П2 (`maskedBy`, `boundaryObservable`), в П1 не заводятся — внутренний тип
растёт вместе со своим производителем.

## Границы и краевые случаи

- **Идентичность — авторская.** Классовая директива материализуется на классе и
  каждом его методе; это привязки одной аннотации. Группировка уже есть в двух
  местах с одним ключом; пакет их не объединяет (одно живёт в чистой функции,
  другое в держателе состояния), а закрывает расхождение тестом — включая
  третий, новый ключ вердикта.
- **Группа сработала, если сработала любая её привязка** — семантика
  сохраняется дословно.
- **`Unmeasured` не то же, что `Inert`.** Сегодня `isAccountable()` возвращает
  `false` по четырём разным путям, и все четыре молча выпадают из отчёта. После
  пакета они выпадают из **находок** (канал прежний), но присутствуют в
  вердиктах с названной причиной. Три из четырёх путей — «директива уже
  отказана» в разных видах, и они сводятся в один `AlreadyRefused`: на все три
  уже отвечает канал `annotation.unresolved-directive`, а повторный ответ судил
  бы одну ошибку дважды — против прямого предписания докблока
  `isAccountable()`. Отдельная причина «канала нет ни у одного продюсера» в
  словаре не заводится: раунд 2 показал, что валидная директива в это состояние
  обычным путём не приходит, а причина, недостижимая на валидном входе, — это
  ветка, которую нечем проверить.
- **Файл без единой находки.** Директива в нём подотчётна и инертна.

## Тестовый план

Единичные, на `DirectiveUsage`, по одному на ветку:

1. Сработавшее подавление → `Effective`.
2. Подотчётное несработавшее → `Inert`.
3. Директива без фильтра правил → `Unmeasured / AddressesEveryChannel`.
4. Отказанная пара `channel:level` → `Unmeasured / AlreadyRefused`.
5. Селектор, не разворачивающийся ни в один канал → `Unmeasured / AlreadyRefused`.
6. Канал без продюсера → `Unmeasured / AlreadyRefused`, и тест доказывает, что
   вход достижим: если валидная директива в такое состояние не приходит, ветка
   снимается, а не покрывается тестом на невозможное.
7. Продюсер выключен селектором → `Unmeasured / ProducerDisabled`.
8. Тот же продюсер выключен через `rules: { X: false }` → тот же вердикт.
9. Классовая директива с пятью привязками, сработала одна → один `Effective`.
10. Два тега разных типов с одним селектором на одной строке → два вердикта.

Проекционный тест: `stale()` возвращает находки ровно по вердиктам с
`effect === Inert`.

Тест ключей: три ключа авторского сайта (`DirectiveUsage`,
`InlineDirectivePolicy`, `DirectiveVerdict`) дают одинаковую группировку на
фикстуре с классовой директивой и на фикстуре из случая 10.

Тест универсума: находка, попадающая под `exclude_namespaces` фикстуры, и
подавление на ней → `Effective`. Мутация «судить по `published`» обязана
покраснеть именно на этом тесте и ни на каком другом.

## Definition of Done

- Дельта канала на `src` измерена до правки и названа: пуста, и пуста по
  монотонности, а не по совпадению. Пересечение с ратчетом проверено — канала
  там нет.
- Десять единичных случаев, проекционный, ключей и универсума — зелёные;
  каждый проверен снятием своей ветки поштучно, мутация красит свой тест и не
  красит остальные.
- Манифест: новые типы объявлены с владельцем `Analysis.Policy.Inline` и
  видимостью `internal`, вне `Contract/` — чужого потребителя у них в этом
  пакете нет, а запись потребителя, которого ещё не существует, проверяющий
  отвергает (`unused contract consumer entry`).
- `composer check` — exit 0; `composer gate -- --reference=<origin/main>` —
  диффы только объявленной дельты, каждый назван.
- README `src/Analysis/Policy/Inline/` дополнен словарём вердиктов;
  `CHANGELOG.md` — запись `Fixed` про универсум.
- Коммит и полная цепочка до начала П2.
