# Х3-F — разнородная популяция для контроля эквивалентности

Закрывает две записи `FOLLOWUPS.md`: «Контроль эквивалентности силён ровно
настолько, насколько разнороден наш `src`» и «Разнородный прогон контроля
эквивалентности некуда положить». Гейт: нет.

Редакция вторая: ревью проверило посадку вердиктов исполнением и нашло, что
предложенный пол не является полом того, что пакет чинит. Разделы «Решение»,
«Контракты» и «Кейсы» переписаны целиком.

Зависимость: пакет читает `scripts/directive-narrow-control.php` в состоянии
**после** пакета C-1, который переписал его чтение отчёта.

## Что измерено до планирования

Измерение 2026-09-02, перепроверено ревью 2026-09-03. Способ: чтение скрипта,
прогон продукта, посадка вердиктов на временных деревьях вне репозитория, замер
времени, прогон cs-fixer и PHPStan по кандидату в фикстуры.

**Цель зашита сильнее, чем сказано.** Скрипт не читает ни `$argv`, ни путь к
конфигурации: цель — константа, `-c` не передаётся ни в один из двух прогонов.

**Конфигурацию, однако, прогон всё-таки видит** — через рабочий каталог: продукт
подхватывает `qmx.yaml` из корня, откуда скрипт его и запускает. Измерено: одна
и та же фикстура из корня даёт `{"inert":1,"unmeasured":2}`, а из своего каталога
`{"inert":3}`. Значит «без `--config` — умолчания продукта» было бы **сменой
смысла** сегодняшнего прогона по `src/`, а не сохранением его.

**Сегодняшняя популяция.** 43 вердикта, все `Effective`: 31 пороговый и 12
символьных. Под полом контроля ходят только пороговые.

**Сужение двигает только измеренные пороговые вердикты** — скрипт говорит это
сам. Значит пол «каждое значение `DirectiveEffect` встречается хотя бы раз»
разнородности словаря требует, а различающей популяции — нет: фикстура из шести
директив со всеми четырьмя вердиктами и двумя измеренными порогами этот пол
проходит, оставаясь вырожденной.

**Ветки коалиций прячутся не в вердикте, а в причине.** Запись заведена ровно
из-за них, а коалиция наблюдаема через одно из четырёх значений
`DirectiveUnmeasurableReason`. Пол по вердиктам её не покрывает.

**Посадка вердиктов даётся не целиком.** `Effective`, `Overrun`, `Inert` и две
причины (`already-refused` через неизвестный канал, `producer-disabled` через
выключенное правило) сажаются с первой попытки. Две причины сопротивлялись:
`@qmx-ignore — причина` без фильтра правил вообще не даёт сайта, а две
`@qmx-threshold` одного правила в одном докблоке дают один вердикт, второй молча
теряется — `masked` при этом не появляется. Рецепт на все четыре причины
считается **неизвестным** и добывается исполнением до реализации.

**Ловушки формы:** `channel=100` молча теряется (нужен пробел и `-- причина`);
`Overrun` требует явных `warning`/`error` по обе стороны измеренного значения,
короткая форма даёт `Effective`.

**Инфраструктура фикстуры проверена.** cs-fixer правилами проекта: 0 файлов к
правке, докблочные директивы не трогаются. PHPStan: каталог фикстур Inline уже
исключён целиком. PHPUnit фикстуру не обнаружит. Каталог фикстур **попадает** в
`docs/internal/generated/modular-architecture/test-ownership.tsv` — по строке на
файл, и без ручных деклараций манифеста `check:artifacts` покраснеет.

**Механизма исключений у перечислителя директив нет.** `enumerate-inline-directives.php tests`
находит четыре сайта, из них два — в существующей фикстуре; спасает только цель
`src`. Инвариант «посаженные директивы не попадают в измерения дерева» держится
соглашением, и новая фикстура его нагрузит.

**Цена.** `composer directives:narrow-control` — 72.5 с (узкий 15.7, полный
56.4). Прогон по фикстуре — 0.27 с.

## Архитектурное решение

**Контроль получает цель и конфигурацию.** Оба прогона внутри одного сравнения
обязаны видеть одно дерево и одну конфигурацию. Прогон по `src/` передаёт
корневой `qmx.yaml` **явно** — иначе пакет незаметно переопределит смысл
сегодняшнего контроля; прогон по фикстуре передаёт её собственный конфиг.

**Пол разнородности — про различающую популяцию, а не про словарь.** Он состоит
из трёх требований: измеренных пороговых вердиктов не меньше названного минимума
(это то, что сужение вообще может двигать); каждое значение `DirectiveEffect`
встречается; каждое значение `DirectiveUnmeasurableReason` встречается. Третье —
единственный машинный способ удержать ветки коалиций, ради которых запись и
заведена; в прозе оно не удержится.

**Фикстура живёт в репозитории и не заражает измерения дерева.** Инвариант
проверяется тестом: перечисление по `src/` не содержит ни одного сайта из
каталога фикстур. Это дешевле, чем заводить перечислителю механизм исключений, и
честнее, чем полагаться на цель.

**Наш `src/` из контроля не уходит**: он про настоящую популяцию, фикстура — про
словарь. Код возврата цели — худший из двух.

**Исходы «прогон невалиден» получают свой код.** Сегодня десять мест бросают
голое исключение и дают 255: неразбираемый JSON, error-envelope, код вне {0,2},
расхождение кода и отчёта, неполный охват, ноль проанализированных файлов,
пустой список вердиктов, ноль измеренных порогов, расхождение `scope`/`selection`,
разные множества сайтов. Пакет, объявляющий «255 не остаётся», обязан их
перевести — иначе это обещание без фондирования.

## Контракты

```php
// scripts/directive-narrow-control.php
--target=<path>            обязателен
--config=<path>            обязателен: молчаливое умолчание меняет смысл прогона
--require-heterogeneity    включает пол разнородности
--min-measured=<n>         минимум измеренных пороговых вердиктов (по умолчанию 1)
```

Коды: 0 — совпало; 1 — разошлось; 2 — популяция не удовлетворяет полу
разнородности; 3 — прогон невалиден (все десять сегодняшних исключений); 7 —
отчёт неузнаваемой формы (общий с гейтом после C-1). Необработанных 255 не
остаётся, и это проверяется перечислением десяти мест, а не утверждением.

`composer directives:narrow-control` исполняет два прогона: `src/` с корневым
конфигом и без требования разнородности; фикстуру с её конфигом, с
`--require-heterogeneity` и с минимумом измеренных порогов.

Фикстура: `tests/Analysis/Policy/Inline/Fixtures/NarrowControl/` плюс её
`qmx.yaml`. Скелет фикстуры (какая форма даёт какой вердикт и какую причину)
добывается исполнением **до** написания кода и вносится в этот план — иначе
пакет потратит бюджет на повторное открытие того, что уже дважды не далось.

## Кейсы и граничные условия

- `Overrun` требует обеих границ; тест проверяет именно `Overrun`, а не «не
  `Effective`».
- Все четыре причины неизмеримости присутствуют. Если какая-то окажется
  недостижимой из авторского кода — это **находка**, и она идёт в
  `FOLLOWUPS.md` вместе с сужением пола, а не тихо выпадает из фикстуры.
- Фикстура чиста по PER-CS (cs-fixer её форматирует) и не обнаруживается
  PHPUnit.
- Каталог фикстуры не попадает в `enumerate-inline-directives.php src` и в
  сверку популяции гейта.
- Манифест: новые файлы фикстуры декларируются руками, `test-ownership.tsv`
  перегенерируется.
- Прогон по фикстуре детерминирован: никаких путей вне её каталога и никакой
  зависимости от корневого конфига.

## Definition of Done

1. `composer directives:narrow-control` — 0, и в выводе видно оба прогона с их
   целями и конфигами; текст «MATCH» называет цель.
2. Прогон по фикстуре печатает распределение вердиктов и причин; все четыре
   вердикта и все четыре причины ненулевые, измеренных порогов не меньше
   минимума. Числа — из прогона.
3. Пол проверен снятием трижды: убери единственный `Overrun` → код 2; убери
   единственную причину `masked` → код 2; опусти число измеренных порогов ниже
   минимума → код 2. Каждый раз возврат правки даёт 0.
4. Мутация «сужать всегда не тем правилом» (та самая, что раньше проходила
   зелёной) прогнана на фикстуре: контроль обязан покраснеть **сравнением
   вердиктов**. Если краснеет чем-то другим или не краснеет — пакет цели не
   достиг, и это говорится прямо, а не считается закрытым.
5. Десять мест, дававших 255, перечислены поимённо, и для трёх из них показано
   исполнением, что теперь возвращается 3.
6. Тест «перечисление по `src/` не содержит сайтов фикстуры» зелёный и проверен
   снятием (временно перенеси фикстуру внутрь `src/` — тест обязан покраснеть).
7. `QMX_MKDOCS=<основной checkout>/website/.venv/bin/mkdocs composer check` — 0.
8. `composer directives:controls` — 0.
9. Цена названа: секунды обоих прогонов, измеренные.

## Что пакет не закрывает

Корпус `finding-gate/` остаётся вне этого контроля: он намеренно внешний, а
директивы здесь — предмет нашего дерева. Инвариант «фикстуры не попадают в
перечисление» держится тестом, а не механизмом самого перечислителя; запись об
этом заводится тем же коммитом.
